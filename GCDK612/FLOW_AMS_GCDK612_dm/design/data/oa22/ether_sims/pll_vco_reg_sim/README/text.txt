Simulation:     VCO_REG_sim 

Purpose:        Transient simulation of the VCO control voltage regulator       
PLL_VCO_REG block for a given VCO control voltage. The simulation is meant 
to check the operation of the PLL_VCO_REG for a given VCO control voltage. 

States:         tt

Description:    The VCO_REG_sim testbench contains an instantiation of the
VCO control voltage regulator, PLL_VCO_REG. The control voltage regulator, 
PLL_VCO_REG block converts the control voltage from the loop filter node to 
the ring supply voltage in the VCO. In the test bench, ideal sources are used 
for power and current references. The control voltage is set by a dc voltage 
source through the net Vcntl. The control voltage on the Vcntl node is set to 
a voltage that would couse the frequency of the output clock from the VCO is 
close to 250MHz. The power down signal, PD is connected to ground through a 
zero voltage source. The test bench also contains an instantiation of the loop
filter block, PLL_160MHZ_LF. The combination of PLL_160MHZ_LF, cap C0 and the
resistor R0 model the load on the PLL_VCO_REG block. The control voltage 
regulator, PLL_VCO_REG block converts the control voltage from the loop filter 
node to the ring supply voltage in the VCO.
 

Verification:   The VRING output voltage of the PLL_VCO_REG can be checked to
make sure it is valid. The output voltage range of PLL_VCO_REG and the tracking
of Vcntl by VRING can be checked by sweeping the control voltage Vcntl from VSS
to VDD using a parametric simulation.

Input Signals:  Vcntl

Output Signals: VRING
